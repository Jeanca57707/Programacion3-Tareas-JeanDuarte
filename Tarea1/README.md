## Jean Carlos Duarte Inoa Tarea Uno

# Descripción general

La tarea uno son un subconjunto de ejercicio que abracan conceptos básicos de java como las decisiones,
bucles, operaciones, herencia, clases, etc... La tarea fue colocada para práctcar estos conceptos y tener
un mejor dominio. Se puede acceder a cada ejercicio a través de un menu con las diferentes opciones, cada una llevandolo a un ejercicio diferente,

# Descripciones breves de cada ejercicio

## Ejercicio Uno
Una calculadora básica que maneja las operaciones de suma, resta, división y multiplicación,
Le pide al usuario dos números y la operacion que debe  realizar.

## Ejercicio Dos
Un pequeño programa que determina si un número es par o impar, tambies determina si el número es positivo o negativo, o si simplemente es 0.

## Ejercicio Tres
Un programa que muestra la tabla de multiplicar de un número dado por el usuario, la tabla mostrada va del 1 al 10.

## Ejercicio Cuatro
Un programa que escribe todos los números del 1 al 100 con un bucle. Simplemente eso.

## Ejercicio Cinco

Clase Persona. Un programa que pide ciertos datos de una persona y los muestre por pantalla.

## Ejercicio Seis
Clase Rectangulo. Una clase con ciertos atributos, que luego en el menu el usuario ingresa los datos de la base y la altura, y el programa le devuelve el perímetro y el área de dicho rectangulo.

## Ejercicio Siete
Clase Empleado. Una clase empleaado que hereda de Persona y que tambien calcula el bono de dicho empleado y muestra su información.

## Ejercico Ocho
Clase Abstracta "Figura". Crear una Clase abstracta llamada figura, dentro de ella contiene un método llamado "calcularArea" y de ahí se creó otras dos clase clases (Círculo y Triángulo) que usen este método de formas distintas.

## Ejercicio Nueve
Contador de vocales. Es un programa que cuenta las vocales de una frase o palabra ingresada por el usuario.

## Ejercicio Diez
Clase Estudiante. Se le pide 5 materias con sus calificaciones y el programa calcula el promedio V evalua si el estudiante Aprobó o Reprobó.

# Tecnologías Usadas
