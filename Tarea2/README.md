## Jean Carlos Duarte Inoa Tarea Dos

# Descripción general

La tarea número 2 es un programa que administra el personal de una universidad X en cual hay Profesores, Administrativos y personal de Mantenimiento. El objetivo de esta tarea es manejar los conceptos de Encapsulamiento y Polimorfismo en java. Tambien se trabaja con conceptos anteriormente vistos como lo es la Herencia, SuperClases, subclases, interfaces y más, el programa lo que hace es mostrar la información de cada empleado. ejecutar el trabajo que cada empleado hace mediante polimorfismo, Mostrar el tipo real de cada objeto, Calcular el bono a los empleados que implementen la interfaz "Bonificable", calcula el total general de todos los salarios, encuentra el empleado con el sueldo mas alto y muestra cuantos empleados existen de cada tipo.

# Tecnologías Usadas

Java v26.0.1 , Visual Studio(Su versión más reciente), Git y GitHub.
