## Descripción

Este programa simula de forma básica un gestor de gastos mensuales. Puedes agregar un presupuesto mensual, luego puedes ir agregandogastos que modificarán el presupuesto que habías colocado anteriormente. EL programa también te indica que tanto has gastado y que tanto queda. Te lo hace ver de forma visual y textual. También está la opción de eliminar gastos, retornando el valor que se había gastado al presupuesto.
